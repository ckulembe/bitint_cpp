# Bit Int

O objectivo desse exercício, é implementar, do zero, uma versão do `bitnum` - ou seja, uma estrutura de dados
que representa números que não podem ser implementados pelos tipos de dados convencionais representados pelos
nossos computadores, como `int`, `long`, `unsigned long` e outros mais. Para isso estruturas de dados, como `vector<...>` ou mesmo `deque<...>`, ou mesmo classes como `string` são usadas para representar esses
números, dando nos assim a possíbilidade de manipula-los como se fossem números comuns.
